# 🌐 HTML/CSS & Frontend

Репозиторий включает в себя проекты, созданные в процессе изучения вёрстки, адаптивного дизайна, работы с семантикой, методологией БЭМ и базовым JavaScript

---

## 🚀 Проекты в репозитории

### 🚀 Интерактивные веб-приложения

#### 1. Mesto (Проект от Яндекс Практикума)
* **Описание:** Интерактивное одностраничное приложение, в котором реализован полноценный интерфейс для публикации фотографий. Поддерживает добавление, удаление карточек, просмотр изображений, систему лайков и просмотр статистики карточек
* **Стек технологий:** HTML5, CSS3 (БЭМ, Flexbox/Grid), JavaScript (DOM, асинхронные запросы, работа с API)
* **[👉 Смотреть на GitHub Pages](https://rmakaida.github.io/mesto-production/)**

#### 2. SaveAnimals
* **Описание:** Лендинг с упором на интерактивность и визуал. В проекте реализованы CSS-анимации элементов интерфейса и валидация формы обратной связи с выводом кастомного всплывающего уведомления (`alert`)
* **Стек технологий:** HTML5, CSS3 (Keyframes Animations), JavaScript
* **[👉 Смотреть на GitHub Pages](rostrost3.github.io)**

### 🛒 Вёрстка по макетам (Figma) и шаблонам

#### 3. Project
* **Описание:** Двухстраничный сайт для онлайн магазина техники, состоящий из главной страницы и страницы с тарифными планами. Реализована интеграция медиаконтента (демонстрационное видео в исходных файлах)
* **Стек технологий:** HTML5, CSS3

#### 4. Wiki
* **Описание:** Учебный информационный сайт-справочник, моделирующий страницу онлайн-энциклопедии. Основной фокус сделан на правильной семантической разметке текстовых блоков и настройке веб-типографии для комфортного чтения больших объемов информации
* **Стек технологий:** HTML5, CSS3

#### 5. MusicPlayerWebSite
* **Описание:** Адаптивная вёрстка интерфейса музыкального плеера на основе Pixel-Perfect макета из Figma
* **Стек технологий:** HTML5, CSS3 (Flexbox)

#### 6. Project1 & Project2
* **Описание:** Практические песочницы для отработки навыков позиционирования элементов, работы с сетками (Flexbox/Grid) и создания адаптивных интерфейсов под разные экраны по готовым шаблонам
* **Стек технологий:** HTML5, CSS3
