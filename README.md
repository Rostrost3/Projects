# 🌐 .NET Applications (Backend & Fullstack)

В этой ветке собраны мои проекты по веб-разработке: от бэкэнд-сервисов (Web API) до полноценных Fullstack-приложений (Blazor). Проекты отражают мой путь от базового синтаксиса до архитектурных паттернов, работы с безопасностью и контейнеризации

---

## 🚀 Основные проекты (Fullstack & Web API)

### 🛒 Shop (Fullstack App)
Полноценный интернет-магазин с разделением прав доступа и динамическим интерфейсом
* **Стек:** ASP.NET Core, Blazor (компоненты, состояние), Entity Framework Core, SQL
* **Реализовано:**
    * Система аутентификации и авторизации (Вход / Регистрация)
    * **Ролевая модель:** Панель администратора с возможностью CRUD-управления товарами (создание, удаление, редактирование)
    * **Клиентский UI:** Каталог товаров с "умным" поиском на лету, интерактивная корзина (добавление/удаление) и логика оформления заказа

### 📊 FinShark (Web API)
Продвинутый REST API сервис для симуляции инвестиционного портфеля и анализа акций. Разработан в рамках углубленного изучения архитектурных паттернов .NET
* **Стек:** .NET Web API, Entity Framework Core, SQL, JWT (JSON Web Tokens), Identity Core, Swagger/OpenAPI
* **Реализовано:**
    * Защита эндпоинтов с помощью **JWT-токенов** (генерация, валидация, разделение прав)
    * Связи «один-ко многим» и «многие-ко-многим» в БД (Акции <-> Комментарии <-> Портфели пользователей)
    * Полное документирование API через Swagger

### 📝 NotesApp (Backend & DevOps)
Приложение для хранения заметок с фокусом на информационную безопасность и контейнеризацию
* **Стек:** ASP.NET Core, Cryptography API, Docker, База данных (SQL/PostgreSQL)
* **Реализовано:**
    * **Безопасное хранение:** Реализованы алгоритмы шифрования данных. Текст заметок и пароли пользователей шифруются на бэкэнде перед отправкой в базу данных (в БД данные хранятся исключительно в зашифрованном виде)
    * **DevOps-пакет:** Проект полностью упакован в **Docker**-контейнер (написан Dockerfile), настроено поднятие приложения и базы данных через `docker-compose`

### 🏃‍♂️ HabitTracker (Fullstack & DevOps)
Fullstack-приложение для отслеживания привычек с единой экосистемой авторизации и контейнеризацией
* **Стек:** .NET 10 (Blazor, ASP.NET Core Web API), EF Core, JWT, MS SQL Server, Docker, Docker Compose
* **Реализовано:**
    * **Fullstack-архитектура:** Реализован интерактивный UI-интерфейс на фреймворке **Blazor**, интегрированный с серверной частью на базе контроллеров ASP.NET Core Web API для обработки бизнес-логики
    * **Безопасность и JWT:** Интегрирована аутентификация на базе JWT-токенов. Параметры авторизации и строки подключения разделены: для локальной разработки используются файлы настроек (`appsettings.json`), а для Docker-окружения реализован безопасный проброс секретов через переменные среды (`.env`)
    * **Автомиграции:** Настроен автоматический накат миграций базы данных при старте приложения через EF Core, что упрощает первый запуск на чистой системе
    * **DevOps и Оркестрация:** Проект упакован через многоэтапный `Dockerfile` (Multi-stage build). Настроено совместное развертывание монолита и базы данных одной командой через `docker-compose` с изоляцией сетей и сохранением данных через Volumes

## 🛠️ Лабораторные и практические проекты (Учебные)

### 🔐 Encryption Project (ASP.NET Core MVC)
Интерактивное веб-приложение для демонстрации классических алгоритмов криптографии
* **Стек:** ASP.NET Core MVC, Razor (`.cshtml`)
* **Суть:** Классическая архитектура MVC. На представлении (`.cshtml`) реализована форма с выбором из 3 исторических шифров (**Цезаря, Виженера, Атбаша**). Контроллер принимает текст, передает его в модель бизнес-логики для шифрования/дешифрования на C# и возвращает обновленный View пользователю

### 📚 BookManage (ASP.NET Core MVC)
Веб-приложение для каталогизации и менеджмента книжного фонда
* **Стек:** ASP.NET Core MVC, Razor (`.cshtml`), Entity Framework Core
* **Суть:** Отработка паттерна MVC и базовых навыков фильтрации/сортировки. Реализован пользовательский интерфейс для добавления книг, поиска по ID, а также кастомная сортировка по названиям, авторам или году издания на уровне контроллера и БД

### 🔑 Registration (Security Practice)
Экспериментальный проект для глубокого понимания протоколов безопасности
* **Стек:** ASP.NET Core, JWT
* **Суть:** Чистый бэкэнд-проект без CSS-верстки, созданный специально для изоляции и тестирования механики работы JWT-классов, генерации клеймов (Claims) и механики логина/регистрации

2.  **Защита данных:** Работа со строгими паролями, хэширование, авторизация через токены (JWT)
3.  **Архитектура и контейнеры:** Работа с ORM (EF Core), вынос инфраструктуры в Docker
