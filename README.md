## 🚀 Проекты в репозитории

### 1. AI Automated Student Answer Grading System
Прототип интеллектуальной системы автоматической проверки и оценивания развернутых ответов учащихся по обществознанию на основе реального датасета объемом ~19 330 записей

Все исследования, проектирование признаков (Feature Engineering) и обучение моделей проводились в облачной среде **Google Colab** с использованием выделенных аппаратных ускорителей (GPU)

* **Задача:** Бинарная классификация ответов студентов (верно / неверно) на основе сопоставления с обратной связью преподавателя
* **Реализованный пайплайн:**
  1. Очистка, токенизация и лемматизация текста средствами `pymorphy3`
  2. Генерация семантических эмбеддингов через `SentenceTransformer` и расчет **косинусного сходства (Cosine Similarity)**
  3. Вычисление метрик перекрытия n-грамм `ROUGE-1`, `ROUGE-2`
  4. Сравнительный анализ моделей: Baseline (`LogisticRegression`, `RandomForest`), Градиентный бустинг (`XGBoost`) с поиском гиперпараметров и кастомная нейросеть на `PyTorch`

### 🛠️ Основной технологический стек (ML/NLP)
* **Разработка и вычисления:** Google Colab Environment (T4 GPU)
* **Data Processing & Analytics:** `pandas`, `numpy`
* **NLP & Embeddings:** `sentence-transformers` (`SentenceTransformer`), `pymorphy3` (русскоязычная лемматизация), `rouge` (ROUGE-1/2)
* **Machine Learning:** `XGBoost` (`XGBClassifier`), `RandomForestClassifier`, `LogisticRegression`
* **Deep Learning:** `PyTorch`
* **Visualization:** `matplotlib`, `seaborn`
