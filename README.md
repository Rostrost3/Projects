## 🚀 Проекты в репозитории

### 1. 2D Traffic Dodge
Простая аркадная мини-игра, разработанная на платформе .NET Windows Forms.

* **Геймплей:** Игрок управляет автомобилем, который движется вперед по бесконечной дороге, и должен уворачиваться от встречного и попутного трафика (других машин), а также собирать монеты
* **Реализованная логика:**
  1. **Игровой цикл (Game Loop):** Реализация движения объектов и сбора монет
  2. **Обработка коллизий (Collision Detection):** Отслеживание пересечений границ объектов (Hitbox) для фиксации столкновений
  3. **Управление:** Обработка событий клавиатуры для перемещения автомобиля игрока по полосам
 
* **Стек технологий:** С#, .NET Windows Forms
