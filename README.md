# 🤖 Telegram Bots Development

Репозиторий содержит проекты по разработке асинхронных Telegram-ботов

---

## 🚀 Проекты в репозитории

### ⚽ 1. GuessFootballPlayer (Викторина-квиз)
* **Описание:** Интерактивный игровой бот-викторина на футбольную тематику. Бот генерирует карточку игрока и предлагает пользователю 4 варианта ответа для угадывания. Для удержания внимания пользователя и повышения интерактивности внедрена механика случайной отправки кастомных стикеров в процессе игрового цикла
* **Стек технологий:** C#, .NET, Telegram.Bot (NuGet), Async/Await, Callback Queries, Inline Keyboards

### 📜 2. TgBotPhilosophicalQuotes (Цитатник философов)
* **Описание:** Бот для поиска и чтения философских мыслей. Поддерживает генерацию случайных цитат, а также расширенный функционал фильтрации: выборку по конкретному автору/философу или полнотекстовый поиск по ключевым словам внутри базы цитат
* **Стек технологий:** C#, .NET, Telegram.Bot

### 🛠️ 3. TgBotAiogram (Базовый асинхронный эхо-бот)
* **Описание:** Практический проект, на котором отрабатывались фундаментальные архитектурные концепции библиотеки Aiogram. Реализованы продвинутые фильтры контента, обработка различных типов медиафайлов и защита от ошибок при копировании сообщений
* **Стек технологий:** Python, Aiogram 3.x, Asyncio
